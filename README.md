# QuickMemo

QuickMemo は、Chrome のサイドパネルで Markdown メモを編集する拡張機能です。メモは選んだフォルダに、1 件につき 1 個の `.md` ファイルとして保存します。Vivaldi のメモも取り込めます。

## インストール

1. このリポジトリをダウンロードまたはクローンします。
2. Chrome で `chrome://extensions` を開き、「デベロッパー モード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、`vivaldi-notes` フォルダを選びます。
4. QuickMemo のサイドパネルを開き、歯車ボタンから保存先を選びます。

詳しい使い方と開発手順は [QuickMemo の説明](vivaldi-notes/README.md) を参照してください。
