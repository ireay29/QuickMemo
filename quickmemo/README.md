# QuickMemo

Chrome のサイドパネルで Markdown メモを編集できます。保存先は Finder で扱えるフォルダで、メモ 1 件につき `.md` ファイル 1 個を作ります。

## 読み込みと保存先の設定

1. Chrome で `chrome://extensions` を開き、「デベロッパー モード」を有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」から、この `quickmemo` フォルダを選びます。
3. ツールバーの「QuickMemo」を開き、サイドパネル上部の歯車ボタンを押します。設定タブで「保存先を選ぶ」を押して、たとえば `~/Documents/メモ` を選びます。必要なら選択ダイアログでフォルダを作成してください。
4. サイドパネルでメモを書けます。左側に置くには Chrome の「設定 → デザイン → サイドパネル」で左側を選びます。

更新を反映するには、`chrome://extensions` で QuickMemo の再読み込みボタンを押し、サイドパネルを開き直します。

保存先を変えると、選んだフォルダの内容に切り替わります。権限が切れたときは「アクセスを許可」を押してください。サイドパネルから許可できない Chrome では設定タブから操作します。今回限りの許可を選んだ場合は、作業中は設定タブを開いておいてください。 [Chrome のフォルダアクセス許可](https://developer.chrome.com/blog/persistent-permissions-for-the-file-system-access-api)

## メモを書く

- 画面と本文のカーソルは Chrome のライト・ダーク表示に追従します。サイドパネルの外枠は Chrome のテーマ色で、メモの領域はライト・ダークに応じた無彩色で表示されます。
- 「新規メモ」で選択中のフォルダにファイルを作ります。タイトル、本文、出典URLの変更は自動保存されます。タイトルを編集してもファイル名は維持します。
- 本文ではMarkdownの見出し、太字、斜体、コードなどの書式が編集中に反映されます。カーソルを置いた行では書式の記号も確認できます。箇条書きで Enter を押すと次の項目が始まります。1行の中で本文の文字を選び、`⌘B`（Windowsでは `Ctrl+B`）を押すと太字を切り替えられます。
- メモ一覧と本文の間のバーを上下にドラッグすると、高さを調整できます。バーにフォーカスを合わせて上下の矢印キーでも調整でき、位置は次に開くときも引き継がれます。
- サイドパネルからフォルダを作り、タイトル、本文、出典URLを検索できます。「再読み込み」で Finder や外部エディタでの変更を読み直します。保存の直前に外部変更を検出した場合は、「コピーを保存」で編集中の内容を別ファイルに残せます。別のアプリと同時に書き込む際は、双方の書き込み順を制御できません。
- ファイルへの保存に失敗しても、Chrome 内に残った下書きは「下書きを開く」から開き直せます。再保存、別ファイルへの保存、Markdown のダウンロードを選べます。「後で続ける」で下書きを閉じ、ほかのメモに移れます。「QuickMemoから応答がありません」と表示された場合は、パネルを閉じたり拡張を再読み込みしたりする前に「Markdownをダウンロード」で原稿を保存してください。
- HTTP または HTTPS のページで文章を選び、右クリックの「メモに保存」を押すと、文章とページURLを保存先の直下に保存します。書き込めない間はクリップを Chrome に保留し、切り抜いた時点の保存先へのアクセスが戻ると保存します。保存先の設定前のクリップは、保留分を処理する時点で選択されているフォルダに割り当てます。Chrome 内への保留にも失敗した場合は、サイドパネルに表示します。

## アーカイブとゴミ箱

- メモを開いて「アーカイブ」または「ゴミ箱へ移動」を押すと、通常の一覧と検索から外れます。上部の「アーカイブ」「ゴミ箱」を選ぶと、移動したメモを閲覧・検索できます。
- 「元に戻す」で元のフォルダに戻せます。同名のファイルがある場合は別名で戻します。本文を編集するには、先に「元に戻す」を押してください。
- 完全に削除するには、ゴミ箱で対象のメモを開き、「完全に削除」を押して確認します。
- 一覧の「複数選択」で、チェックしたメモをまとめてゴミ箱へ移せます。「表示中をすべて選択」は、検索やフォルダで絞り込んだ結果を選びます。検索条件、フォルダ、一覧の切り替えで選択は解除されます。ゴミ箱で複数選択して「完全に削除」を押すと、実行前に対象件数を確認できます。
- 保存先直下の `QuickMemo アーカイブ` と `QuickMemo ゴミ箱` は管理用の名前です。既に同名のフォルダがあれば、中のメモも対応する一覧に表示します。QuickMemo で移動したメモは元のフォルダ階層を保つので、Finder から `.md` を確認できます。管理用フォルダを外部で入れ子にした場合は、復元先が管理用フォルダの中になるメモを保存先直下に戻します。
- 移動が中断され、移動元と移動先のどちらにも元の内容を確認できない場合は、「下書きを開く」から原稿を開き、「コピーを保存」で復旧できます。

## Vivaldi から移行する

- **Markdown フォルダ**を使う場合は、Vivaldi で「ファイル → エクスポート → メモをエクスポート」を実行し、設定タブの「Markdown フォルダを取り込む」で保存先と重ならないフォルダを選びます。UTF-8 の `.md` の内容と、そのファイルを含むフォルダ階層を保ちます。既存の `.md` をその場で使いたい場合は、そのフォルダを直接保存先にできます。
- **Vivaldi の Notes ファイル**を使う場合は、「Vivaldi Notes を取り込む」で、macOS の既定プロファイルなら `~/Library/Application Support/Vivaldi/Default/Notes` を選びます。その場所を開けない場合は、Finder で `Notes` を書類フォルダへコピーして選んでください。ゴミ箱の分は「Vivaldi のゴミ箱」フォルダに入ります。タイトルが空なら、本文の最初の空白でない行から Markdown の見出し記号を外し、最大72文字を使います。画像などの添付ファイルは対象外です。

保存先フォルダ全体をバックアップするには、Finder でフォルダをコピーします。設定タブの「JSON 書き出し」には、アーカイブとゴミ箱を含め、現在の保存先にある読み取り可能な UTF-8 の `.md` が入ります。空フォルダ、Chrome 内の下書き、保留中のクリップは対象外です。「JSON から復元」は選択中のフォルダにメモを追加する操作です。同名のファイルがあり内容が異なる場合は別名で保存します。

## エディタの依存ライブラリ

CodeMirror は同梱済みです。更新時はリポジトリの `tools/quickmemo-editor` で `npm ci` と `npm run build` を実行します。同梱ライブラリのライセンスは [LICENSES.txt](vendor/LICENSES.txt) を参照してください。
